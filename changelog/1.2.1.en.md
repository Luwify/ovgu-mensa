Changed:
- Updates are now installed only after confirming them in the Android install dialog.
- Holding a card to the phone no longer starts an update check. The check runs only when the app itself is open.
- Payments are no longer matched to the menus during a scan, but the next time the app or the statistics are opened.
- The card ID is now used only with card statistics turned on and after a successful read.
- The “Download” button in the note about Stundenplan MD opens its release page on GitHub in the browser.
